# Pokémon Cīņas Simulators ⚡💧

## Apraksts
Objektorientēta Java programma ar GUI (JOptionPane), kas ļauj:
- Izveidot Pokemonus (Elektriskais / Ūdens)
- Apskatīt statistiku
- Cīnīties (ar tipa efektivitāti)
- Attīstīt Pokemonus
- Dzēst Pokemonus

## Funkcionalitāte
- **Polimorfisms**: uzbrukt(), izsauciens(), attistities()
- **Pārmantošana**: ElektriskaisP, UdensP no Pokemons
- **Abstraktā klase**: Pokemons
- **Ievades validācija** ar regex un JOptionPane

## Klases
| Klase              | Atribūti | Metodes            |
|--------------------|----------|--------------------|
| Pokemons (abstraktā) | 6        | 4 (3 abstraktās)   |
| ElektriskaisP       | +0       | 3 override         |
| UdensP              | +0       | 3 override         |
| Metodes             | -        | 2 statiskās        |

## Kā palaist
1. Kompilē visus `.java` failus  
2. Palaid `MainMenu` klasi
